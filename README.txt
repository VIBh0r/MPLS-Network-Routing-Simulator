How to Compile
---------------
g++ -std=c++11 -O2 -o mpls mpls_simulation.cpp

(clang++ works identically in place of g++)

How to Run
----------
./mpls

To save the console output to a file:
./mpls > output.txt 2>&1

What the Program Does
----------------------
- Task 1: Represents the fixed 4-router topology (R0-R1:10, R0-R2:20,
  R1-R3:20, R2-R3:10) as an adjacency/cost matrix.
- Task 2: Runs Dijkstra's algorithm from every router to build and print
  each router's Routing Information Base (RIB) in the required
  "Destination | Next Hop | Total Cost" format.
- Task 3: Defines the single Forwarding Equivalence Class used by this
  simulation - "all traffic originating from R0 and destined for R3".
- Task 4: Builds the Label Forwarding Information Base (LFIB) for that
  FEC's Label Switched Path (R0 -> R2 -> R3), using the label values given
  in the assignment (Push 300 at R0, Swap to 777 at R2, Pop at R3). The
  ingress router's next hop is read directly from the Task 2 RIB, so Task 4
  is built on top of Task 2 rather than being an independent hardcode.
- Task 5: Simulates one packet traveling from R0 to R3 through that LSP,
  printing the push/swap/pop trace hop by hop.
